# KR5

Контрольная работа №5

## Описание

Проект запускается локально через uvicorn
Проект запускается в Docker-контейнере
Для HTTP-эндпоинтов использованы FastAPI и Pydantic-модели
Для проверки работы API добавлены интеграционные тесты на pytest и TestClient
Для WebSocket-части использованы WebSocket, WebSocketDisconnect
